# Producer notes per template

Add one file per template, `<template-slug>.md` (e.g. `knitted-doll-story.md`), written by or with the creative
producer who built it. The `lyra-templates` skill reads it before adapting that template. Keep each file short:

```markdown
# Knitted Doll Story

**Makes:** 9:16, ~15 s, 3 scenes, voiceover + music.
**Why it works:** <the insight — e.g. the handmade look stops the scroll; the doll is a neutral stand-in any audience projects onto>.
**Safe to change:** the product in scene 2's prompt, the voiceover script (keep ≤ 35 words), the end card text.
**Do not change:** the knitted/wool material words, the warm window light, the slow push-in, the 3-scene order.
**Best for:** <app categories / audiences>.  **Avoid for:** <where it flops>.
**Uploads:** app icon (PNG, square) into "Logo"; one app screenshot into "Screen".
**Known issues:** <e.g. Kling sometimes adds extra fingers to the doll — regenerate scene 1 before animating>.
```

Template titles and uuids come from `list_templates`. Use the title as the heading so the skill can match the note to the template.
